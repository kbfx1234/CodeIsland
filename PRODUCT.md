# Product

## Register

product

## Users

Developers who run one or more AI coding agents on macOS and need to monitor work, handle requests, and return to the correct terminal, IDE, or desktop conversation without breaking focus.

## Product Purpose

CodeIsland is a personal, public fork that turns the MacBook notch or menu-bar area into a compact control surface for AI coding agents. It takes Vibe Island as a product reference while developing its own integrations, workflows, visual language, and open-source direction.

## Brand Personality

Compact, reliable, playful. The interface should feel like a focused developer utility, with pixel mascots adding character without reducing clarity.

## Anti-references

Do not copy Vibe Island branding, copy, or assets. Avoid oversized islands, sparse compact states, decorative motion, color-only status communication, and counters such as `1/1` when they add no useful information.

## Design Principles

1. Put the current agent state and required action ahead of decorative information.
2. Use the smallest surface that still communicates useful context.
3. Make jumps, approvals, and answers reliable before adding more integrations.
4. Preserve user-owned CLI configuration and keep local data local.
5. Keep pixel-art personality subordinate to legibility and predictable macOS behavior.

## Accessibility & Inclusion

Respect Reduce Motion. Communicate waiting, completion, and error states with text or symbols as well as color. Keep compact labels readable under truncation and support the project's localized interfaces.
